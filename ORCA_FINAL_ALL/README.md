# ORCA — Marine Ecosystem Intelligence

## Run
1. Open this folder in VS Code.
2. Open Terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the Vite localhost URL.

Do not open `index.html` directly.

## Included
- Cinematic ocean opening with supplied ocean-depth video
- ORCA reveal + live ocean message/status feed
- Light/Dark mode buttons with saved preference
- Monitoring regions
- Ocean Intelligence Map with Ecosystem/Thermal/Currents/Satellite layers
- Ocean vital signs: temperature, oxygen, fish population, pollution, salinity, pH, waves, biodiversity, chlorophyll
- 7 collaborative agents: Ocean, Marine Life, Satellite, Human Activity, Risk, Prediction, Reasoning
- Live reasoning trace and explainability
- Ocean Digital Twin
- Source monitoring
- Trend analysis and 7-day ecosystem forecast
- NASA GIBS satellite context
- Mission matrix: marine heatwaves, HAB, oil/pollution, coral bleaching, fisheries, cyclone/coastal, blue carbon, maritime safety
- Ask ORCA
- What-if Lab
- How to use + What is ORCA

Model/demo values are labeled as telemetry/simulation unless connected to a validated live source.
